How to verify the current dashboard

  1. Run python3 build_site.py; it fails on broken internal links, inconsistent calculated totals, malformed tables, or leaked markup.
  2. Open a hotel row’s dated Booking.com source and compare the selected room, rate, and cancellation terms.
  3. Check each official activity source; date-specific closures and the February 2027 ferry timetable still need a later re-check.
  4. Compare every derived amount with the formula in the Method page and source values in site_data/*.json.

Remaining repository limitations

  • No licence file; that decision belongs to the owner.
  • The legacy builder is blocked by missing docs/data/michelin_2025.csv.
  • No automated CI currently runs the canonical build.
  • No historical price-series archive exists beyond the dated weekly snapshots.
