How to verify this session's work

  1. Every data row: open the source link on the row and compare. Hotel prices were read from the Booking.com room table with the same dates in the URL — the URLs in the table reproduce the price.
  2. Every blank: cross-check against the flag list. If a blank is missing from the flag list, that is a defect worth reporting.
  3. Every model: the formula is on the method page; the inputs are in docs/data/*.csv, so the numbers can be recomputed.
  4. Build: run python3 build.py and confirm the pages regenerate byte-identically.
