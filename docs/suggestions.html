Missing Information — How to Discover

  • Hotel prices: Use official hotel booking engine; capture total for same room type across date windows. Record currency, taxes/fees, and cancellation terms.
  • Restaurant costs: Use official menu/tasting menu pages. Where only prix-fixe is listed, compute for 2 adults and label exclusions (wine pairing, supplements, tip).
  • Transit: Use MTA and Google Maps "Depart at/Arrive by" for representative times; record exact duration and transfers.
  • Michelin status changes: Re-check each restaurant's Michelin Guide page before final itinerary; Michelin awards can change annually.
  • Closures/holidays: Check official restaurant/activity pages for Feb 15–18, 2027 and any holiday/special closure notices.

Suggestions are advisory. Review and prioritize before implementation.
