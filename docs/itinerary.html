A day-by-day plan that only puts dinners on days the sources say the restaurant is open.

Reservation logic

  • Three three-star dinners in seven nights is a lot of tasting-menu food. Two is realistic; pick Eleven Madison Park + Le Bernardin, or Per Se + Sushi Sho.
  • Every verified restaurant's booking platform is recorded (Resy for Le Bernardin and EMP, Tock for Per Se, Sushi Sho, Aquavit and Jungsik) — the link is on the restaurants page. Release windows are not yet captured: that is suggestion S1.
  • Lunch is a cheaper way into the same kitchens: Le Bernardin serves 12–2:30pm Mon–Fri, Aquavit 12–2pm Mon–Fri, EMP 12–1pm Fri–Sun (per MICHELIN pages).
