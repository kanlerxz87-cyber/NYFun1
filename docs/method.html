Method & sources

Source dates, calculations, unresolved disagreements, known build limitations, and the checks used to generate the site. Dataset check dates differ; the footer date is not a claim that every source was re-read that day.

Rules and dates

  • Read it or leave it blank. A field is shown only when it was captured from a linked source; unavailable values stay blank with a reason.
  • Never infer. No typical prices or assumed venue hours. Social handles not directly verified are explicitly labelled unconfirmed or left as searches.
  • Separate awards from listings. The star roster is the 2025 ceremony article; current filter counts are shown separately.
  • Label arithmetic. Derived totals are marked and formula inputs are available in site_data/.
  • Source dates: hotel pages and current MICHELIN filters were read 2026-11-26; the activity dataset is dated 2026-11-26. Restaurant detail and social data retain their own earlier checks. One Chelsea Market Instagram reference remains unconfirmed (F-08).

Budget basis

The $4,184.98 priced subtotal sums each nonblank budget line for two adults: the derived seven-night Fairfield Booking-line estimate, a one-adult airfare doubled, the MTA cap for two, six activity-ticket lines, and two tasting menus. It is not a full trip budget; ordinary meals and discretionary costs remain unpriced.

Travel-time model and limits

The hotel reach table is only a 5 km straight-line comparison radius, not an estimate of travel time. The non-ferry activity minutes use great-circle distance from area-level hotel coordinates, divided by an assumed average walking or effective subway speed, plus a fixed platform/access allowance. These activity values are screening models, not MTA routes or door-to-door schedules.

Liberty Island requires a ferry. The February 2027 sailing schedule and full journey time were not available in the schedule checked, so the earlier 56-minute land-mode value is invalid and the activity is not counted under one hour (F-05, F-20, Q-19).

Build and verification

python3 build_site.py is the active generator. It validates source links, derived hotel arithmetic, the priced subtotal, table row widths, internal links, duplicate IDs, and escaped/template markup before reporting success.

Archived builder limitation: the older python3 build.py expects docs/data/michelin_2025.csv, which is absent from this checkout. The chained legacy build stops at that file and does not run build_deepdive.py. The canonical dashboard is generated from site_data/*.json instead; the archived deep-dive output is not validated by this build.
