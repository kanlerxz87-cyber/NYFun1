Method & sources

How every number on this site was produced, every official source read on 2026-11-26, the few remaining third-party walls, and the automated integrity checks run on every build.

Rules the site is built on

  1. Read it or leave it blank. A value appears only if verified on a linked primary/official source or authoritative search record.
  2. Never infer. No invented daily meal allowances, no guessed handles, no fabricated schedules.
  3. Separate the award from the listing. Red stars, Green Stars (including One White Street Selected), Bib Gourmand (76), and Selected (224) stay strictly separated.
  4. Label every derived number. NYC tax math (14.75% + $4–$6/night + $1 Arlo tourism) and Haversine distances are explicitly marked DERIVED/MODEL.
  5. Reconcile disagreements explicitly. The 72-entry ceremony vs 69 live NYC list discrepancy is fully accounted for name-by-name (F-02).
  6. Date every snapshot. Verified snapshot date: 2026-11-26.

Build checks

python3 build_site.py refuses to succeed if any of these fail:

  • Budget subtotal matches the sum of priced lines within $0.005.
  • Zero unrendered template braces, double-escaped entities, leaked raw tags, or bare-hash placeholder anchors.
  • Zero duplicate element IDs and zero broken internal links across docs/*.html.
  • All superseded legacy files (e.g. docs/methodology.html, docs/data/build_summary.json) remain absent.
