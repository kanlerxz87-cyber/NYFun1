Method, verification tiers and every source

How each number was produced, what was refused, and the complete list of pages read in this pass.

Verification tiers

Tier A — official page, field read

The value appears verbatim on an official site we fetched (MICHELIN Guide, the museum, Booking.com's own room table). These values are shown normally.

Tier B — official page, field missing

We fetched the official page but the field did not render (Met hours, AMNH hours, ESB, High Line). The value is blank and flagged — we did not substitute a plausible number.

Tier C — secondary source only

Independent guides agree (e.g. "The Met is closed Wednesdays"), but we could not read it on the official site. Shown with an explicit PARTIAL badge and the caveat on the row.

MODEL / DERIVED — our arithmetic

Tax-inclusive totals, spend envelopes, transit minutes and the hotel score. Always labelled. Never mixed silently into a verified column.

Transit model

Straight-line distance is computed from coordinates. Time is the better of:

  • Walk: 80 m/min (4.8 km/h) + 2 min buffer.
  • Subway/bus: 8 min platform access + wait, then 18 km/h average including stops.

This is a deliberately crude two-mode model. It is directionally right for Manhattan and understates cross-borough trips. It was chosen because the MTA trip planner is a JavaScript application that could not be read programmatically in this pass, and we would rather publish a labelled model than an unlabelled guess. Every restaurant row links out to a transit query so a human can check in one click (flag F13).

Hotel score

score = access_index ÷ (tax-inclusive 7-night price ÷ 1000) × amenity_bonus, where access_index = 3×(verified starred restaurants ≤20 min) + 2×(≤30) + 1×(≤60), and amenity_bonus = 1 + 5% for included breakfast + 5% for a guest score ≥ 8.5. The weights are a judgement call, published so you can disagree with them. Because all four hotels reach all six verified restaurants inside 30 minutes, the score is effectively doing two things: rewarding the cheapest all-in price and rewarding breakfast.

Price handling

Hotel prices are Booking.com 7-night totals for 2 adults, 1 room, captured 2026-11-25. The site displays the listed total and a derived all-in figure using the tax treatment stated on the page (14.75% NYC hotel tax + $4/night city tax). Promotions are named where they applied (a "Black Friday" rate, valid for select stays 19 Nov 2026 – 31 Dec 2027). Nothing is averaged or smoothed.

Link policy

Direct links are used where a page was actually fetched. For social/video, this pass did not verify individual YouTube, TikTok or Instagram posts, so every row carries a search link rather than a fabricated profile URL. That is intentional: a search link is honest, a guessed handle is not.

python3 build.py

The generator reads docs/data/*.csv and writes every HTML page. Data files: michelin_2025.csv, guide_listed.csv, hotels.csv, date_windows.csv, activities.csv. Content registers (flags, questions, suggestions, itineraries, budget) live in content.py.
